## Updating future LinkedIn Learning courses
1. Put the PDF certificate into `assets/documents/`.
2. Add one card in the `#learning .credential-grid` section of `index.html`, with its exact course title, completion date and local PDF path.
3. Commit to `main` for automatic publication.
